# INT8 diagnosis — raw outputs

Supporting data for `../INT8_DIAGNOSIS.md` (Task A1). One folder per sweep run with
`quantization_report.json` (or `float_control_report.json`), the INT8 sha256 and, where scored,
`test_evaluation_summary.json`. `.tflite` files are not committed.

- `sweep_tables.md` — validation tables generated by `scripts/a1_table.py`.
- `v1_diagnose.json` — `run_quant_diagnose --trace` output for v1 (stage report + per-node trace).
- `v1_pixel_stats.json` — brightness-temperature statistics of v1 splits vs the INT8 input range.
- `scripts/` — the sweep and scoring scripts exactly as run (local paths replaced by `${REPO}`, `${WORKSPACE}` = parent of the repo, `${SCRATCH}` = working dir; set them before running).
  v1 runs used `main`'s labelling code on `v1_view_pre0830` plus this branch's quantization package;
  v4 runs used this branch at 900e097.
